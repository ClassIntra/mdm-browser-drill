H 组 · 宿主层被动相对请求探针

本页经 域名形态通道加载（保证可进入）。页内自动发出四类请求，用于判定「当前宿主 WebView 内是否有 host 层过滤器」。
本页 UA：
单变量对照设计（H3 / H4 物理等价，仅 IP 字符串不同）：
· H3 阳性：http://192.168.40.90:9011/px.png → 在黑名单 → 预期被拦
· H4 阴性：http://100.99.237.111:9011/px.png → 同一台机器、同一端口、同一文件，IP 不在黑名单 → 预期放行
判读表（以服务端 access.log 落账为准）：
· H3 被拦 + H4 到达 = 该宿主有 host 层过滤器
· H3 也到达 = 该宿主无过滤器（或过滤器不查子资源）
· H1/H2 结果用于判断「相对路径是否被查」——若相对路径也拦，说明过滤器在 URL 解析后判断，与输入形态无关
